Spotify non connecté

Pour te connecter une fois pour toutes, il faut un Client ID Spotify gratuit (2 minutes) — aucun serveur nécessaire :

  1. Va sur developer.spotify.com/dashboard → Create app.
  2. Dans Redirect URIs, ajoute l'adresse de cette page (voir bouton ci-dessous).
  3. Coche Web API → Save.
  4. Copie le Client ID et colle-le ici.
